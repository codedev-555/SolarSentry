**"Find Your Real Solar Costs. Expose the Scams."**

🔗 **Live Demo:** [https://reflex.run](https://reflex.run)

---

## About the Project
**SolarSentry** is a consumer-protection web application built for the **Congressional App Challenge**. Shopping for residential solar panels often involves confusing quotes, hidden lease markups, and high-pressure sales tactics. SolarSentry empowers homeowners with transparent financial estimates and automated quote analysis so they can make confident, scam-free clean energy decisions.

### Key Features
- 📊 **Smart Cost Estimator:** Calculates realistic solar installation costs tailored to your household's energy usage and setup.
- 🛡️ **Scam Detection Engine:** Analyzes solar quotes and contract terms to flag inflated pricing, hidden fees, and predatory sales red flags.
- 💰 **Buy vs. Lease Comparison:** Breaks down long-term costs, savings, and return on investment between buying solar panels outright versus leasing them.

## Running Locally
To run SolarSentry on your own computer:

1. **Clone the repository**
   ```bash
   git clone https://github.com
   cd YOUR-REPO-NAME
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Start the Reflex app**
   ```bash
   reflex run
   ```
   Then open `http://localhost:3000` in your browser.
